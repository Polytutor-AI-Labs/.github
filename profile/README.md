<h1 align="center">PolyTutor AI Labs</h1>
<p align="center"><b>Smart trading. Real edge.</b></p>

PolyTutor AI Labs builds open-source trading bots for Polymarket and other prediction markets, along with market makers, quant research and AI agents. Every strategy is researched and backtested in the open before it trades.

## Repositories

| Repository | Description |
| --- | --- |
| ⭐ [**polymarket-trading-bot-strategy**](https://github.com/Polytutor-AI-Labs/polymarket-trading-bot-strategy) | PolyTutor overview of Polymarket trading bots: strategy guides (copy trading, market making, dump-hedge, last-seconds, sports), case studies, and engineering notes. Smart trading. Real edge. |
| ⭐ [**polymarket-strategy-handbook**](https://github.com/Polytutor-AI-Labs/polymarket-strategy-handbook) | PolyTutor research handbook documenting 39 Polymarket strategies across 14 families: execution mechanics, backtesting methodology, risk and failure modes. Never trust the strategy. Test the strategy. |
| ⭐ [**polymarket-ai-trading-bot**](https://github.com/Polytutor-AI-Labs/polymarket-ai-trading-bot) | Rust AI trading workspace for Polymarket: ML stacking ensemble + OpenAI LLM paper-betting bot and a leaderboard copy-trading bot, with Postgres ledger, Python model server and Grafana monitoring. |
| ⭐ [**polymarket-5min-btc-Jev-trading-bot**](https://github.com/Polytutor-AI-Labs/polymarket-5min-btc-Jev-trading-bot) | Terminal agent for Polymarket BTC Up/Down 5-minute markets that asks the TypeSafe Jev model for UP/DOWN calls; dry-run by default, opt-in fill-or-kill live orders. |
| ⭐ [**polymarket-black-scholes-hft-bot**](https://github.com/Polytutor-AI-Labs/polymarket-black-scholes-hft-bot) | Real-time HFT bot for Polymarket crypto Up/Down markets combining CLOB order books, Chainlink feeds and multi-exchange prices with TWAP and Black-Scholes probability models; paper mode and backtests. |
| ⭐ [**preditfun-market-maker-trading-bot**](https://github.com/Polytutor-AI-Labs/preditfun-market-maker-trading-bot) | Passive market-making bot for Predict.fun: quotes from live order books, replaces stale orders and cancels on unsafe price/depth; Windows desktop app and web console for Ubuntu servers. |
| [**polymarket-adaptive-trading-desk**](https://github.com/Polytutor-AI-Labs/polymarket-adaptive-trading-desk) | Adaptive trading desk running four competing strategies on Polymarket BTC 5-minute markets, learning from resolved trades, with copy trading and a live dashboard. |
| [**polymarket-avellaneda-stoikov-market-maker**](https://github.com/Polytutor-AI-Labs/polymarket-avellaneda-stoikov-market-maker) | Market maker for Polymarket BTC binaries: Black-Scholes fair value, Avellaneda-Stoikov inventory skew, optional Hyperliquid hedge, plus a PPO reinforcement-learning quoting policy for comparison. |
| [**polymarket-btc-5min-black-scholes-bot**](https://github.com/Polytutor-AI-Labs/polymarket-btc-5min-black-scholes-bot) | Edge finder for Polymarket BTC 5-minute Up/Down markets pricing binaries with Black-Scholes against live Binance volatility, with paper A/B testing and published research findings. |
| [**polymarket-mcp-agent**](https://github.com/Polytutor-AI-Labs/polymarket-mcp-agent) | MCP server that lets Claude Code, Cursor and other AI clients read Polymarket markets and, in live mode, sign and post CLOB orders; preview mode simulates trades in SQLite. |
